# 维科夫实时行情识别 V1.0 专业评审与优化建议

评审日期：2026-10-21  
评审对象：[维科夫实时行情识别规范 V1.0](WYCKOFF_MARKET_RECOGNITION_V1.md)  
评审性质：维科夫理论语义、量化识别工程和研究方法评审；未进行市场样本回测  
交付范围：独立评审报告，原 V1.0 文档保持原样，便于逐项核对

## 1. 评审结论

**建议：保留总体架构，先修订为 V1.1，再进入完整识别实验。**

这份 V1 的最大价值是：把量价事实、结构解释和交易决策分开，并明确了真实可用时间、边界版本及失效处理。这些设计符合实时识别的核心要求。

它尚不能视为完整、经过验证的维科夫阶段识别系统。主要问题不是某个成交量倍数是否合适，而是存在可以构造反例的规范缺口，以及容易造成覆盖偏差的规则组合。之前完成的表格、JSON 和一致性初查不等于理论和状态机已经通过专业评审。

| 维度 | 评审判断 | 原因 |
|---|---|---|
| 理论边界 | 基本合理 | 没有把 Composite Man 当成可直接观测的参与者，未把区间根数当确定目标价 |
| 因果性设计 | 架构合理，局部需补充 | 已分开发生和可用时间，但两根模式的前置上下文仍有口径缺口 |
| 规则可执行性 | 修订后可进入实现 | 普通突破、深穿分支、Phase E 和非默认参数映射尚不完整 |
| 结构覆盖 | 有明显范围限制 | 内部 LPS/LPSY、低量顺畅推进、复杂回调和多次测试覆盖有限 |
| 统计有效性 | 尚未建立 | 缺少实测覆盖率、增量检验、相关样本处理和稳定性结果 |
| 实盘交易价值 | 当前无法判定 | 本次未评估手续费、滑点、执行和样本外收益 |

文中“可能降低覆盖率”“可能增加噪声”均为待验证的建模判断；有数值反例的问题则明确标为规范缺口，不将两者混为一谈。

## 2. 应当保留的设计

1. 因果性、真实可用时间、数据版本与前缀回放原则。
2. 事实事件和结构假设分开存储，失败不抹掉原发生事实。
3. 原事件引用冻结边界；新边界必须另建版本，不事后挽救信号。
4. 识别器与交易层分离，不把 SC、Spring、BUEC 名称当收益保证。
5. `not_evaluable`、`not_implemented`、`expired` 和 `invalidated` 分开。
6. 不强迫所有结构经过唯一的 SC→AR→ST→Spring→SOS 路径。
7. 所有市场阈值视为研究参数，默认概率为空。

以上架构可以延续到 V1.1。固定水平边界、SMA、Wilder ATR 和特定波浪分配方法属于版本选择，不是永远不得研究的理论原则。

## 3. 必须先修订的规范问题

本节问题无需优化市场参数就可以判断。优先级“必须先修订”表示完整状态识别实现之前应解决，不代表存在资金损失的已证实结果。

### 3.1 Phase E 缺少同向运动条件

位置：V1 第 5.1 节，305—311 行；第 9.1 节，762 行。

ER 使用净位移绝对值，反映方向效率，不提供上涨或下跌方向。Phase E 条件只要求连续在区间外、ER 足够高和离边界有足够距离，缺少有符号位移或同向趋势。

反例：旧阻力 R=100，最近 20 个变化从 130 单调下降至 110，全部收盘仍在阻力上方。ER=1，距阻力仍超过 2 ATR。按现有公式可能得到“向上 Phase E 获支持”，实际当前运动在下跌。

建议明确：

```text
向上Phase E = 边界外连续维持
              AND (C_t-R)/A_ref >= min_distance
              AND signed_delta_n > 0
              AND slope_n > 0
              AND ER_n >= min_er

向下Phase E = 相应的负向位移和负向斜率
```

可以直接引用“当前同向趋势成立”简化实现，也可以保留独立阶段条件，但必须写明方向。位移、斜率和窗口仍待验证。

### 3.2 普通突破的假设生命周期没有完整创建入口

位置：V1 第 6.4 节，475、487、489 行；第 7.5 节，628—639 行。

普通上破只明确输出 `BREAKOUT_UP`；在强 JOC 段落才创建 `UP_BREAKOUT_VALIDITY`。后文却规定任意普通突破均可获得延续确认、失效或超时。向下对应假设的创建也未明确。

反例：低量普通上破，没有满足 JOC，但随后连续三根收于边界上方。没有规定应确认哪个假设 ID，两个实现可能产生不同结果。

建议所有普通突破都创建方向有效性假设：

```text
BREAKOUT_UP   -> create UP_BREAKOUT_VALIDITY
BREAKOUT_DOWN -> create DOWN_BREAKOUT_VALIDITY
JOC / FTI     -> 同一突破事件的强量价特征
```

再定义严格 BUEC 和 LPSY 属于哪些突破子集。若只覆盖强 JOC/FTI，必须显式标记普通突破回测路径的未覆盖范围。

### 3.3 首根深穿被过滤，承诺的深穿事件可能漏报

位置：V1 第 6.3 节，437—443、462 行。

创建观察时已要求刺破深度不超过 2 ATR；深穿记录却在已创建的模式内部检查。第一根直接深穿 3 ATR 时不会建立模式，无法进入深穿分支。

建议先检测下穿事实，再分流：

```text
detect SUPPORT_UNDERCUT
  if depth <= configured_max_depth: create SPRING_RECLAIM_WATCH
  else: emit DEEP_UNDERCUT and optional DEEP_RECLAIM_WATCH
```

“深穿事实”和“深穿后收回”分别记录。UT 镜像同步处理。后续观察是否要求一根或两根收回属于研究参数，不能影响首根深穿事实是否被保存。

### 3.4 两根 UT 的“刺破前上下文”没有冻结

位置：V1 第 6.6 节，508 行；第 9.4 节，821、831 行。

UTAD 候选要求供应占优证据在刺破前已经存在；处理顺序却统一使用检测当根的上一根快照。对于 p 刺破、p+1 收回的模式，检测时的上一根是 p，已经包含刺破后的信息。

反例：供应占优在 p 收盘更新波浪时刚成立；p+1 收回被识别为 UT。若使用 p 的快照，便会错误声称“刺破前已有供应占优”。这不等于使用未来 K 线，但违背了本规则承诺的前置时点。

建议在 p 建立观察对象时保存：

```text
context_asof = p-1
range_age_at_onset
direction_evidence_ids_at_onset
range_version_at_onset
```

收回时只读取该快照。对所有多根事件明确区分“开始时上下文”和“确认时新增证据”。

### 3.5 新候选的失效计数起点存在歧义

位置：V1 第 6.2 节，428 行；第 9.4 节，822—824 行。

连续两根收于支撑下方会使吸收候选失效，但没有写明连续计数是否包含创建根及创建前一根。流程先检查已有候选，再创建新候选，若失效条件在创建当根已满足，可能漏掉检查。

建议逐条登记计数起点，区分：

- 创建前的有效性前置检查。
- 包含创建根的全局价格计数。
- 仅创建后启动的响应计数。

在确认前，再对新候选执行当根适用的失效检查。不能只规定“失效优先”，却没有定义对哪个候选、从何时开始检查。

### 3.6 参数表可调，正文却写死默认公式

位置：V1 第 7.2 节，539 行与参数表 900 行；第 7.5 节，633、635 行与参数表 919 行。

`ar_reversal_close_steps` 可调，正文却只写两次回落；`breakout_fail_deep_fraction` 可调，正文却固定以中点 M 判断。默认值时一致，非默认配置没有统一公式。

建议正文使用参数符号：

```text
AR回折：连续 k 个收盘变化同向，需 k+1 个收盘
上破深度失败：C < S + f*(R-S)
下破深度失败：C > R - f*(R-S)
```

k、f 的默认值另列。同步统一其他窗口公式，明确 N 个价格变化需要 N+1 个收盘。Delta20/ER20 本身索引正确；OLS 当前使用 20 个收盘的独立窗口，不应将其误指为未来泄漏，但要明确与 ER 的跨度不同。

### 3.7 示例输出与严格候选入口需要一致

位置：V1 第 8.4 节，728 行；第 9.3 节，801—808 行。

吸筹候选入口要求方向占优证据和近期 SOS，而示例只列低量 Spring，就显示主假设为吸筹候选。示例可能意在省略证据，但没有声明省略，会误导实现人员降低入口条件。

建议补齐波浪和 SOS 的证据 ID，或把示例主结构改为 `spring_supply_test_candidate`，并显示吸筹方向尚待确认。

## 4. 维科夫语义和识别覆盖的优化

### 4.1 分开“测试发生”和“测试后转强”

位置：V1 第 7.3 节，575—585 行；第 7.4 节，600—615 行。

Spring Test 当前同时要求：靠近支撑、较高低点、低量窄幅、阳线、越过前一根高点。严格 BUEC 又必须出现阳线实体吞没和重启放量。这可以作为一个严格策略模式，但不宜视为全部测试或 LPS 的定义。

建议改为两步：

```text
q：测试形态
   接近已知支撑、没有深度破位、较高低点、供应代理量降低

r：测试后反应
   q之后规定窗口内突破局部反应高点，或出现有效向上推进
```

q 可以是阴线、十字线或阳线；r 可以放量，也可以在较少量能下顺畅推进。保存 `test_observed` 和 `test_response_confirmed`，需要同根完成时将它作为严格子类型。

低量测试配合较高低点是经典证据，原教程并未把“必须吞没上一根实体”规定为所有有效测试的条件。相关经典关系参见 [Wyckoff Analytics 教程](https://www.wyckoffanalytics.com/wyckoff-method/)。上述分步算法是本报告的工程建议，仍需校准。

### 4.2 允许内部 LPS/LPSY，或诚实限制 Phase D 输出范围

位置：V1 第 3.5 节，224 行；第 7.4—7.6 节；第 9.1 节，761 行。

阶段说明允许 Phase D 仍在区间内，但自动 LPS/LPSY 只覆盖 JOC/FTI 后的外边界回测。因此内部 SOS→较弱回调→再次推进无法获得 Phase D 规则支持。

这一范围限制在原文已有部分披露，应避免把它描述成完全隐瞒的理论错误。建议任选一条：

- 补内部路径：SOS 后确定事前已知的局部支撑，低量回调后再推进；SOW 后对称。
- V1.1 暂不扩展：明确 `phase_d_internal_path=not_implemented`，允许 Phase D 候选，避免将未覆盖解释为不存在。

经典 Phase D 注重持续的力量推进和较弱反应，BU 也可能表现为更高处新建区间，并非只有严格触边吞没模式。[Wyckoff Analytics 教程](https://www.wyckoffanalytics.com/wyckoff-method/)

### 4.3 收回规则应区分区间内收回与跨区间复合事件

位置：V1 第 6.3 节，449 行；第 6.6 节，506 行。

Spring 仅要求收盘在 S 上方，没有排除收在 R 上方；UT 的镜像也允许收在 S 下方。下穿支撑后直接跨越整个区间，可以有很强信息，但称为普通“收回区间”不够精确。

建议保持所有基础事实，并分型：

- 区间内收回：标准 Spring / UT 形态代理。
- 越过对侧边界：`undercut_reclaim_and_breakout` 或 `upthrust_reversal_and_breakdown` 复合模式。

复合事件与 SOS/JOC/FTI 建立关联，不重复当作多条独立证据。

### 4.4 方向证据不能只覆盖“大量上涨、小量下跌”

位置：V1 第 8.3—8.4 节，716—732 行。

当前吸筹候选强依赖上行相对量占优和近期高量 SOS，偏向放量推进型结构。供应减少后，价格也可能在不大的需求下上涨；相反，高量下跌但推进很小，也可能提供支撑吸收证据。

建议并列观察三种证据路径：

| 路径 | 价格结果 | 量能解释 |
|---|---|---|
| 需求积极推进 | 上行净推进有效，回撤较弱 | 推进量增加、回调量降低 |
| 供应逐渐枯竭 | 小努力也能向上推进，向下测试受限 | 不要求所有上涨都达到高 RVOL |
| 支撑吸收后响应 | 支撑附近努力大、下行结果小，随后出现向上反应 | 高量弱下行不是自动的派发证据 |

这些都是结构假设，不直接证明筹码所有权。供应枯竭后较少需求也能推动价格的例子参见 [Wyckoff Analytics 教程](https://www.wyckoffanalytics.com/wyckoff-method/)。并列路径及量化指标属于本报告建议，不能预设其预测能力。

## 5. 量化指标和数据处理的优化

### 5.1 日内 ST/Test 使用原始成交量比，抵消了时段标准化

位置：V1 第 4.3 节，278—280 行；第 7.2—7.3 节，550、569、583 行。

RVOL 已使用同交易时段基准，ST/Test 却仍要求原始量小于高潮或 Spring 原量的固定比例。不同 bar slot 的正常成交量差异会影响结果。

反例：Spring 原量 100，同槽基准 200，RVOL=0.5；次日开盘 Test 原量 150，同槽基准 500，RVOL=0.3。Test 的相对努力更低，RVOL 比为 0.6，但 `150<0.65*100` 为假，仍被拒绝。

建议日内跨槽比较以归一化努力为主：

```text
pattern_effort = sum(V_i) / sum(Bv_i)
relative_test_effort = test_effort / reference_pattern_effort
```

模式两根的 effort 不宜直接使用平均原量比较，也不宜一律把各根 RVOL 简单平均视为等权努力。最大 RVOL 可保留为“任一根是否爆量”的独立特征。

日线可同时保留原量比例与相对量比例，分别评估增量；不能未经验证断言其中一种一定更好。

### 5.2 四项方向证据包含重复计票

位置：V1 第 8.3 节，716、719、721 行。

第四项“上行 RVOL≥1.4 且下行≤0.85”必然意味着上行/下行≥1.647，已经满足第一项比值≥1.2。所以满足第四项时量能关系贡献两票；三项通过门槛并不代表三条独立证据。

建议合并为一个努力特征组：

```text
组1：相对努力及其绝对水平
组2：有方向的推进与回撤结果
组3：边界响应和结构序列
```

第一版可以保留分组规则分数，但显示“证据分数”而非概率。速度、波幅和净位移同样可能相关，要用删掉某组的对比实验检验其独立贡献。

### 5.3 波浪极值结果与最终净位移必须同时保存

位置：V1 第 8.1—8.2 节，683—700 行。

现有波浪量累计到反转确认之前，包含从极值退回的尾段；`wave_result` 却使用极值与起点之差。这样可执行、也没有必然未来泄漏，但“量能消耗”和“最终推进结果”不完全对应。

例：上波由 100 上升到 106，再退回 104.5 才结束。极值推进为 6，最终净推进为 4.5，累计量能包含回撤尾段。把极值推进速度直接解释成持续需求占优会丢失回撤信息。

建议保留现有成交量分配方法，同时输出：

```text
peak_excursion = direction*(extreme_close-start_reference_close)/A_start
signed_end_displacement = direction*(end_close-start_reference_close)/A_start
giveback = peak_excursion-signed_end_displacement
path_distance = sum(abs(C_i-C_(i-1)))/A_start
directional_efficiency = signed_end_displacement/path_distance
```

上行 direction=+1，下行=-1。净推进可以为负，不用绝对值隐藏旧“下行波”结束时已净上涨等情况。方向投票使用哪一项需要明确登记和验证。

### 5.4 固定的是事件边界，不是整个市场永远的一组边界

位置：V1 第 5.2—5.4 节，339、365—380 行。

冻结原事件边界值得保留。但单个前台区间最长保留 200 根、内部不研究新边界，会使新区间、边界扩展或趋势中的新整理被旧结构压住。收盘仍在旧宽区间内，也可能被长期强制归为 range。

建议区分：

- **事件参照边界：** S/R/ε 永久保留，决定原信号的成功与失败。
- **当前分析边界：** 只根据已知历史提出新候选，达到明确建立规则后启用新版本。

原区间转为归档，新区间向前生效；不能改写原事件。V1.1 可以仍保持一个前台区间，但应补“区间已不代表近期价格运行”的提前退休条件，并保存明确原因。

### 5.5 换月重置会与日内最低同槽样本叠加

位置：V1 第 4.3—4.4 节，280、287 行。

切换合约后全部重置，再要求至少 10 个同槽交易日样本。如果实现为从切换当天才开始收集新合约历史，就可能产生约 10 个可比较交易日的量能识别空窗。

优先优化为：识别状态按实际合约管理，切换时使用当时已经取得的新合约历史独立预热；不能将旧合约的原区间和量能直接拼接。若提前跟踪多个合约，要冻结主合约选择规则，防止使用事后主力判定。

真实数据缺口、迟到、锁价与无成交也要分别定义处理方式；不能用没有有效成交的锁价 K 线直接确认供应枯竭。

## 6. 研究设计与参数治理

### 6.1 参数数量需要收敛，记录数量不等于需要全部优化

本次按第 10 节表格中的唯一参数名计数，登记了 **103 个参数名**。其中包括预热、开关和重复窗口，并不等于 103 个独立自由度，但联合试验空间依然可能很大。

第一轮建议只开放 6～10 个敏感参数，其余保持基线值：

- 量能基准窗口 / 强量门槛。
- 边界容忍度。
- 区间成熟度。
- 强弱推进的标准化结果门槛。
- Spring 深度 / 收回期限。
- 确认窗口。

先修复公式和分支，再做参数研究。没有必要优先搜索几十个乘数、根数与实体组合。参数邻近扰动后结果是否稳定，通常比单点最佳结果更有决策价值。

### 6.2 硬条件与辅助证据分开

| 规则类别 | 示例 | 推荐处理 |
|---|---|---|
| 语义条件 | 事前已知支撑、确实发生下穿并收回 | 保留为形态必须条件 |
| 强度特征 | RVOL、NS、影线、收盘位置 | 原始值全部保存；严格标签与宽松候选分开 |
| 响应证据 | 测试后的反弹、回撤减弱、延续 | 与测试形态分时记录 |
| 策略筛选 | 必须吞没、必须放量重启、必须指定周期 | 用策略子类型或独立研究配置，避免冒充完整理论定义 |

硬条件叠加会影响覆盖率，但放宽也可能增加噪声，两者都需数据验证。建议保存“距离阈值多少”的连续特征和拒绝原因，避免只有一个真假标签。

### 6.3 评价需要明确事件单位与相关性

V1 已规定时间滚动、分母、purge 和 embargo，这是正确方向。但同一区间多次 SOS、Spring 与重叠未来窗口高度相关，不能默认它们是独立样本。

建议同时报告：

- 原始事件数。
- 独立候选数。
- 交易区间数。
- 确认链条数。
- 去重后的评价样本数。

预先规定每个区间每种路径取第一个候选、最后一个候选或全部候选的具体口径；选择规则必须只使用当时信息。置信区间使用区间聚类或时间块重采样，而不是对高度重叠事件假设独立。

Purging 防止跨集合标签重叠，并不能单独解决同一个样本外集合内部的相关性。删除某些失效候选后只看已确认事件，会造成选择偏差，必须保留候选总体。

### 6.4 分开“当前描述质量”和“未来预测价值”

当前状态识别可以评价响应延迟、稳定性、覆盖范围、解释一致性；未来方向预测需使用单独的客观标签。

不要求人工吸筹标签作为唯一真值。推荐在已知趋势、波动和区间位置相似的样本之间，对比加入事件后是否改变：

- 下一观察窗的方向性净位移与回撤。
- 区间外维持比例及失败深度。
- 上下障碍的先后触及。
- 最大有利 / 不利变动。

若事件只重复均线和普通突破的信息，仍可以提供可读解释，但不能声称产生独立预测优势。

### 6.5 评价锚点与交易锚点分别登记

按信号根收盘作为未来变动的价格锚点，可以用于描述研究；收盘后才知道的信号不能因此被假设在该收盘价成交。

建议保存 `descriptive_reference_price` 和 `execution_reference_price`。只评价识别时允许前者；接入交易层后使用实际可成交时刻和价格。迟到数据也要按真实可用时间开始评价，不把错过的价格移动算成可捕获收益。

## 7. V1.1 的建议实现顺序

### 第一批：修复确定的规范缺口

1. 所有普通突破创建有效性假设。
2. Phase E 添加同向运动条件。
3. 首根深穿建立独立事实分支。
4. 多根模式冻结开始时上下文。
5. 明确失效计数起点，对新候选执行当根适用检查。
6. 正文公式统一引用参数符号，修正示例与入口的不一致。

验收先使用构造价格路径，验证分支与时间顺序；这些检查无法证明市场预测价值。

### 第二批：修正量价测量和测试结构

1. 日内序列比较采用同槽归一化努力。
2. 测试形态与测试后响应分开。
3. 合并重复量能投票。
4. 波浪增加净推进、极值推进与回吐。
5. 明确内部 Phase D 和复合 Spring/UT 的覆盖范围。

### 第三批：做覆盖率和增量研究

依次对比：基础趋势 / 区间模型 → 加事实事件 → 加测试和响应 → 加波浪证据。每次只增加一个模块，报告覆盖率、延迟、失败、样本量与样本外结果。

若严格形态样本很少，优先确定是市场本身罕见、数据不适用，还是规则组合过严。此时不直接堆更多参数。
