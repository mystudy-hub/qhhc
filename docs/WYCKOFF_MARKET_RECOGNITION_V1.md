# 维科夫实时行情识别规范 V1.0

版本日期：2026-10-21  
版本性质：第一版工程基础规范，阈值尚未完成样本外验证  
用途：利用截至当前已收盘的数据，识别行情状态、量价事件及可能的维科夫结构  
基础输入：OHLCV、最小跳动、交易日历、合约和数据版本信息

> 本规范可以指导实现一个确定、可复现的识别器。确定性指“相同数据和配置产生相同结果”，不代表对吸筹、派发、趋势反转或未来收益具有确定性。文中的默认参数均为研究起点。

## 1. 目标、理论边界与输出分层

### 1.1 识别器必须回答的问题

每根 K 线收盘后回答：

- 当前更接近上涨趋势、下跌趋势、震荡区间还是过渡状态？
- 最近发生了哪些可以直接观测的量价事件？
- 哪些结构解释获得了支持？哪些竞争解释仍然成立？
- 下一步出现什么动作会增强判断？什么动作会使判断失效？
- 本次判断使用的数据最晚到什么时候？

识别输出分为三层：

| 层次 | 输出示例 | 确认含义 |
|---|---|---|
| 市场状态 | `downtrend`、`range`、`transition` | 指定规则对当前状态的分类 |
| 结构假设 | 止跌候选、吸筹候选、再派发候选 | 对已知事件链条的解释，允许被后续价格否定 |
| 事实事件 | 宽幅高量、低量下穿收回、上破边界 | 截至当时确实满足了规定条件 |

V1 识别器输出观察和研究信号。仓位、买卖、加仓、止损、成交模拟由独立交易策略决定；不得把结构标签自动解释为已经验证的买点。

### 1.2 三大定律如何进入量化

| 理论概念 | V1 可观测替代量 | 必须保留的解释边界 |
|---|---|---|
| 供求法则：Law of Supply and Demand | 波幅、收盘位置、净位移、上涨和下跌波段的推进效率 | OHLCV 提供供求表现，不能直接观测全部挂单和参与者意图 |
| 因果法则：Law of Cause and Effect | 区间年龄、宽度、触碰、内部量价结构 | 区间根数不直接决定后续涨跌幅；经典目标估计使用点数图横向计数 |
| 努力与结果：Law of Effort versus Result | 相对成交量与波幅、净位移、波段推进的组合 | 大量小位移是背离证据，吸收方向需要上下文和后续反应 |

Composite Man 是理解大资金行为的分析模型。V1 不输出“已证明某机构通过限价单吸筹”等身份或订单行为判断。三大定律和点数图的历史概念参见 [Wyckoff Analytics 教程](https://www.wyckoffanalytics.com/wyckoff-method/)。

V1 不根据“区间持续 N 根”输出确定目标价，不要求先证明市场不存在随机性。评估对象是：识别结果相对简单基准是否具有稳定的增量信息。

### 1.3 使用本规范的操作流程

1. **登记研究对象：** 实际合约、K 线周期、交易时段、成交量单位和数据源；保存规则版本 `1.0` 与参数版本 `v1-default-unvalidated`。
2. **选择输入配置：** 日线使用历史均量；日内使用同交易时段基准。检查样本是否满足指标预热和日内同槽历史，不足则输出具体缺项。
3. **逐根运行：** 按第 9.4 节顺序处理已收盘 K 线，同时保存快照、事件和假设状态转换。
4. **阅读当前结果：** 先看质量和市场状态，再看仍有效的结构假设，最后看下一确认、失效条件和候选期限；历史确认不自动等于当前有效。
5. **收盘后复查：** 汇总新增事件、已确认 / 失效 / 超时的候选，检查是否有数据修订、边界变化或异常切换。每个变化必须能追溯到条件和时间。
6. **开展研究：** 按第 11 节验收因果性并进行样本外评估，按第 12 节逐批校准 P 参数；通过以前使用“未验证基线”标记，不输出未经校准的概率。

首次实现可以用单品种、单周期验证整条流程；之后扩展时，每个“实际合约＋周期”独立维护状态。本文交付的是操作规范，代码实现和市场有效性验证属于后续工作。

## 2. 固定约束与待验证参数的管理

### 2.1 三类约束

“不可更改”必须区分原则、版本约定与待验证阈值，不能把一个未经验证的数字冻结成理论真理。

| 类别 | 含义 | 是否可以更改 |
|---|---|---|
| **I：不变原则** | 因果性、真实可用时间、事实和解释分离、可复现性 | 只要仍称为实时识别器，就不能违背 |
| **F：V1 固定约定** | 公式、枚举、时间计数、边界和波浪划分方法 | V1 同一版本内不能随意更改；修改需升级规则版本并重新验证 |
| **P：研究参数** | 周期、倍数、窗口、容忍度、次数、筛选和模式开关 | 可以在训练和验证阶段校准；运行前冻结配置和参数版本 |

### 2.2 I 类不变原则

| 编号 | 必须遵守的内容 |
|---|---|
| I-01 | 时间 t 的输出只使用在 t 已经到达并可用的数据，不使用未来 K 线、未来拐点或尚未发布的信息 |
| I-02 | `event_time`、`confirmed_at`、`available_at` 分别保存；后续确认不能倒填成原始事件当时已知 |
| I-03 | 事实事件与结构解释分别记录；后续失败不能抹掉过去确实发生的突破或放量事实 |
| I-04 | 当前待检测 K 线不能同时定义自己的突破边界；边界必须在检测前已知 |
| I-05 | 不移动原有边界挽救失败事件；重建区间必须产生新的区间 ID 和版本 |
| I-06 | 缺失数据、指标不可用和未覆盖情形不能用“没有信号”代替 |
| I-07 | 相同数据版本、规则版本和配置产生相同输出；历史解释变化必须有记录 |
| I-08 | 任意规则分数、证据条数和 `confirmed` 标签不能直接称为概率 |
| I-09 | 样本外数据不能用于选参数；有重叠未来标签时，必须隔离泄漏 |
| I-10 | 原始成交量不能直接称为主动买量或主动卖量；方向归属需要额外数据和定义 |

### 2.3 F 类 V1 固定约定

| 编号 | 本版本固定内容 |
|---|---|
| F-01 | 仅使用已收盘 K 线产生正式输出；盘中输出若存在，必须单列为 provisional |
| F-02 | `Spread = H-L`；`True Range` 单独计算；成交量基准和 ATR 比较基准排除当前 K 线 |
| F-03 | ATR 使用 Wilder 平滑；均线使用 SMA；统计中位数偶数样本取中间两数均值 |
| F-04 | 严格按照公式使用 `>`、`>=`、`<`、`<=`；相等不允许程序自行解释 |
| F-05 | 时间窗口以有效交易 K 线计数，不以自然日计数；窗口上下界均包含 |
| F-06 | 支撑和阻力在 V1 是固定水平区域；曲线 Creek、斜向 Ice 不在本版本自动识别范围内 |
| F-07 | 所有候选都采用相同生命周期；每次状态转换追加记录，历史记录不覆盖 |
| F-08 | 波浪划分使用第 8 节的因果方法；不通过未来反转回填历史波浪量 |
| F-09 | Spring 的低量和高量分组是工程分类；阈值未被宣称为 Pruden 或 Wyckoff 的固定数字 |
| F-10 | V1 自动识别的 LPS 是完成规定回测的 BUEC 子集；其他形态明确标记为未覆盖 |

F 类方法可以研究替代方案，例如 SMA 改为 EMA、均量改为中位数、曲线阻力代替水平阻力，但这些属于新规则版本，不属于在同一个 V1 回测中更换参数。

### 2.4 P 类参数的使用要求

第 10 节登记的所有默认数字、数量阈值和功能模式都是待验证项。参数调整要保存：参数名、旧值、新值、适用品种、周期、交易时段、训练区间、样本外结果及修改原因。

运行中的配置不能因为某次信号失败而临时放宽。若以后实施在线校准，更新算法也必须只使用当时可用历史数据，并作为独立规则版本接受验证。

## 3. 术语、缩写和阶段解释

### 3.1 量价和区间基础术语

| 名称或缩写 | 英文全称 | 中文与操作含义 |
|---|---|---|
| OHLCV | Open, High, Low, Close, Volume | 开盘、最高、最低、收盘、成交量，是本版本基本输入 |
| TR（区间语境） | Trading Range | 交易区间：价格反复运行的支撑、阻力区域；不等于 ATR 公式中的 True Range |
| True Range | True Range | 真实波幅，包含相邻收盘之间的跳空；代码用 `true_range`，避免与 Trading Range 混淆 |
| ATR | Average True Range | 平均真实波幅，用于把价格变化转换为可比较的波动单位 |
| RVOL | Relative Volume | 相对成交量：当前成交量与指定历史基准之比 |
| NS | Normalized Spread | 本文自定义缩写，标准化单根波幅 `(H-L)/ATR_previous` |
| CP | Close Position | 本文自定义缩写，收盘在本根高低区间中的位置，0 接近低点，1 接近高点 |
| S / R | Support / Resistance | 支撑 / 阻力；V1 使用带容忍度的水平区域 |
| Creek | Creek | “小溪”，吸筹结构中的阻力带隐喻，实际分析可能不是一根水平直线 |
| Ice | Ice | “冰面”，价格下方支撑带的隐喻；跌穿意味着支撑失守的证据 |
| Absorption | Absorption | 吸收：在成交活跃时价格推进受限的解释；OHLCV 只能检测其代理特征 |
| Stopping Volume | Stopping Volume | 停止量：趋势末端异常成交和价格拒绝继续推进的解释；不意味着单根已证明趋势终结 |
| Weis Wave Volume | Weis Wave Volume | 将成交量按价格波浪累计，以比较不同波浪的努力和推进；上行波量不等于主动买量 |
| P&F | Point and Figure | 点数图，按价格格和反转规则构图；横向计数用于估计潜在目标，V1 不实现目标价模块 |

文中计算与验证缩写补充：

| 缩写或用语 | 全称 / 含义 | 本文具体用途 |
|---|---|---|
| SMA | Simple Moving Average，简单移动平均 | 取指定历史收盘的算术均值，用于趋势位置筛选 |
| OLS | Ordinary Least Squares，普通最小二乘 | 对等距 K 线序号拟合直线斜率，衡量价格或 RVOL 的整体变化 |
| ER | Efficiency Ratio，方向效率比 | 端点净位移绝对值除以逐根变化绝对值之和；接近 1 更具方向性，接近 0 往返更多 |
| LW / UW | Lower Wick / Upper Wick | 本文下影 / 上影占比，区别于收盘位置 CP |
| M | Midpoint | 区间中点 `(S+R)/2`；默认深度失败线使用它 |
| MFE / MAE | Maximum Favorable / Adverse Excursion | 最大有利 / 不利变动，用于信号后的客观评价；需要冻结方向、观察期限和价格锚点 |
| OHLC 回放 | 基于开高低收的历史回放 | 只能知道本根极值，未必知道高低点先后顺序 |
| Purge | 剔除跨分组的重叠标签样本 | 防止训练标签观察期伸入验证或测试区间 |
| Embargo | 分组边界后的隔离期 | 根据标签和样本依赖设置，减少相邻集合的信息重叠 |
| Brier score | 概率预测平方误差的均值 | 校准概率后，检查预测概率与真实二元结果的一致性 |
| provisional | 暂定、盘中预览 | 数据尚未正式收盘，必须与最终识别分开保存 |
| not_evaluable | 当前不可评估 | 必要指标或数据缺失，不能当成条件未触发 |
| not_implemented | 本版本尚未实现 | 功能覆盖范围标记，不是没有市场事件 |

### 3.2 止跌、止涨与测试术语

| 缩写 | 英文全称 | 中文及结构含义 | V1 如何使用 |
|---|---|---|---|
| PS | Preliminary Support | 初步支撑：长期下跌中开始出现明显承接迹象 | 解释性术语，V1 不单独给出已确认 PS |
| PSY | Preliminary Supply | 初步供应：长期上涨中开始出现明显供应迹象 | 解释性术语，V1 不单独给出已确认 PSY |
| SC | Selling Climax | 抛售高潮：下跌末端显著量价异常，可能对应恐慌成交和承接 | 先识别 SC 特征；随后 AR、ST 增强止跌结构证据 |
| BC | Buying Climax | 买入高潮：上涨末端显著量价异常，可能对应抢购和供应 | 与 SC 对称，先识别特征，再观察自然回落和测试 |
| AR（吸筹语境） | Automatic Rally | 自然反弹：疑似 SC 后卖压减弱所伴随的回升，用于形成候选上沿 | 代码固定为 `AR_RALLY` |
| AR（派发语境） | Automatic Reaction | 自然回落：疑似 BC 后需求减弱所伴随的回落，用于形成候选下沿 | 代码固定为 `AR_REACTION`；不能与自然反弹共用方向不明的枚举 |
| ST | Secondary Test | 二次测试：再次接近前期高潮区域，比较供应或需求是否减弱 | 允许小幅越过原极值，但必须满足明确容忍度和量价条件 |
| Spring | Spring | 弹簧：已知区间支撑被短暂下穿，随后收回；是一种潜在向下假突破 | 形态可当下检测，Phase C 和后续上涨仍是待验证解释 |
| Test of Spring | Test of Spring | 弹簧测试：收回后再次接近支撑，低点较高、量能降低，并出现向上反应 | 满足第 7 节的完整条件后，确认对应测试序列 |
| Shakeout | Shakeout | 震仓：较剧烈的向下扫荡；终末震仓可具有 Spring 性质 | V1 深穿情形单独记录，不自动归入低量或高量 Spring |
| UT | Upthrust | 上冲回落：短暂越过阻力后跌回区间，是潜在向上假突破 | 先识别形态，不自动认定派发 |
| UTAD | Upthrust After Distribution | 派发后上冲：成熟派发结构后期的需求测试 / 诱多式上冲 | 必须有成熟区间及供应占优上下文，不能把所有失败突破都叫 UTAD |

Spring #1、#2、#3 属于不同教学体系中用于区分刺破力度和供应表现的分类。V1 仅把“低量 Spring，常称 #3”和“较高量 Spring，需要后续测试，常称 #2”作为显示别名；主事件代码使用 `SPRING_LOW_VOLUME`、`SPRING_HIGH_VOLUME`。`RVOL<0.8`、`RVOL>1.3` 和刺破深度是本规范的研究参数。其他成交量区间保留 `SPRING_OTHER`，不强行编号；剧烈破位保留 `DEEP_UNDERCUT`。

### 3.3 JOC、JAC、SOS、BUEC、BU、LPS 的详细区别

| 缩写 | 英文展开 | 中文及操作含义 |
|---|---|---|
| SOS | Sign of Strength | 力量信号：上涨表现出相对宽幅、较高量能和较有效的向上推进；可以发生在区间内部 |
| JAC | Jump Across the Creek | 越过小溪：价格越过已知阻力区域的向上动作 |
| JOC | Jump Over the Creek | 同一隐喻的另一种常用缩写；本版本统一事件代码为 `JOC`，显示时允许 JAC 别名 |
| BU | Back-Up / Backup | 回撤或回到突破区域的过程，范围较广，可以是简单回调，也可能是更高处新建区间 |
| BUEC | Back Up to the Edge of the Creek | 回到小溪边：突破后回测原阻力转成的支撑区域；本文亦接受 Backup 拼写 |
| LPS | Last Point of Support | 最后支撑点：SOS 之后回调中显示供应减弱、需求重新占优的支撑点；可能不止一个 |

**SOS 与 JOC：** SOS 描述力量表现，JOC 额外要求越过一个在事前已知的阻力区域。区间内部出现宽幅高量上涨可以是 SOS，但不是 JOC。普通低量上破则是 `BREAKOUT_UP`，未必满足 V1 的强 JOC 规则。

**BU 与 BUEC：** BU 是更宽的回撤过程；BUEC 要求回到“旧阻力附近”。一个回调一直在旧阻力远上方横盘，可以属于广义 BU，但不满足 V1 的 BUEC 触边条件。

**LPS 与 BUEC：** BUEC 描述位置和过程，LPS 描述回调支撑及后续需求反应。回到了小溪边，尚未出现合格向上反应时，只能叫 BUEC 候选；通过规定确认后，V1 才同时输出 LPS。经典 LPS 也可能在区间内部或更高支撑处形成，本版本没有全面覆盖这些形态。

**为什么 JOC 后还需要观察 BUEC？** 收盘可以确认上破事实，但无法永久证明它不会失败。缩量回测并重新向上推进，增加“突破区域成为支撑”的证据。BUEC 不是每次上涨都必须出现，也不能永久证伪 UTAD 或保证盈利。

**数值示意：** 事前阻力 R=100，容忍度 ε=0.2；价格收于 102 且满足宽幅高量规则，记录 JOC。之后回调最低到 100.1，回调量能降低，再出现规定向上反应，确认 BUEC/LPS 序列。如果随后连续收盘跌回 99.5、99.4，即使之前完成 BUEC，也必须撤销“该突破当前仍有效”的解释。数值仅用于说明。

SOS、BU、LPS 的经典位置关系与可能存在多个 LPS 的说明参见 [Wyckoff Analytics 教程](https://www.wyckoffanalytics.com/wyckoff-method/)。本规范的英文别名统一和数值门槛属于工程约定。

### 3.4 向下结构的对应术语

| 缩写 | 英文全称 | 中文及与向上结构的区别 |
|---|---|---|
| SOW | Sign of Weakness | 弱势信号：宽幅、较高量能和有效下行推进，可以发生在区间内部或下沿附近 |
| FTI | Fall Through the Ice | 跌穿冰面：跌穿事前已知支撑的动作；本版本采用 `FTI` 作为强向下突破代码 |
| LPSY | Last Point of Supply | 最后供应点：SOW 后反弹表现无力，原支撑附近出现供应、再次转弱的位置 |
| Markup | Markup | 拉升阶段，价格离开区间后持续向上运行 |
| Markdown | Markdown | 下跌阶段，价格离开区间后持续向下运行 |
| Accumulation | Accumulation | 吸筹解释：区间内量价行为逐步支持供应减弱和需求占优 |
| Distribution | Distribution | 派发解释：区间内量价行为逐步支持需求减弱和供应占优 |
| Re-accumulation | Re-accumulation | 再吸筹：更大上涨背景中的区间整理及后续上行解释 |
| Re-distribution | Re-distribution | 再派发：更大下跌背景中的区间整理及后续下行解释 |

FTI 是支撑失守事件，SOW 是弱势表现，LPSY 是下破或转弱后反弹失败的证据。它们不能仅靠名称自动赋予派发或未来下跌的确定性。V1 的反弹回测规则是第 7 节 BUEC 规则的工程对称版本，不声称所有市场在上涨和下跌时具有相同统计分布。

### 3.5 Phase A—E

| 阶段 | 吸筹方向的常见含义 | 派发方向的常见含义 | V1 输出原则 |
|---|---|---|---|
| A | 原下跌开始停止，可能出现 SC、AR、ST | 原上涨开始停止，可能出现 BC、AR、ST | 有止跌或止涨证据，不等于永久反转 |
| B | 区间内部运行，逐步形成潜在上涨条件 | 区间内部运行，逐步形成潜在下跌条件 | 区间成熟不等于方向已知 |
| C | 对剩余供应的测试，可能出现 Spring | 对剩余需求的测试，可能出现 UT/UTAD | Spring 和 UTAD 都不是必备路径 |
| D | SOS 与较弱回调 / LPS 增强需求占优证据 | SOW 与较弱反弹 / LPSY 增强供应占优证据 | 可以仍在区间内向边界推进，不要求已完全离开区间 |
| E | 离开区间后的明显拉升 | 离开区间后的明显下跌 | 用延续条件识别，不在首次突破时直接宣布 |

阶段是结构解释。V1 保存 `phase_candidate` 和 `phase_supported_by_rules`；不能要求所有行情走唯一的 SC→AR→ST→Spring→SOS→BUEC 路径。允许多次 ST、多次 LPS、无 Spring 的结构以及方向暂不明的区间。上述经典路径变体参见 [Wyckoff Analytics 教程](https://www.wyckoffanalytics.com/wyckoff-method/)。

## 4. 数据输入、计算定义与时间口径

### 4.1 必需字段

```text
symbol, actual_contract, timeframe, bar_start, bar_end, trading_day
open, high, low, close, volume, tick_size
is_closed, received_at, data_source, data_version
session_id, is_roll_boundary, quality_flags
```

`actual_contract` 在合约切换时必须可识别。不能将连续合约代码当成永不变化的实际合约。`open_interest` 可作为额外描述字段，V1 不使用它判定某机构吸筹或派发。

基本合法性：`H>=max(O,C)`、`L<=min(O,C)`、`H>=L`、`V>=0`、时间有序、同一合约同一周期无重复主键。不得要求期货价格永远大于零；基于价格比例的扩展指标需另设定义。

### 4.2 成交量与波幅

令 t 为当前已收盘 K 线，`A_t = ATR_(t-1)`：

```text
true_range_t = max(H_t-L_t, abs(H_t-C_(t-1)), abs(L_t-C_(t-1)))

ATR 初始值 = 前 n_atr 个可计算 true_range 的算术平均
ATR_t = ((n_atr-1) * ATR_(t-1) + true_range_t) / n_atr

Bv_t = mean(V_(t-n_volume), ..., V_(t-1))
RVOL_t = V_t / Bv_t

Spread_t = H_t-L_t
NS_t = Spread_t / A_t
CP_t = (C_t-L_t) / Spread_t
LW_t = (min(O_t,C_t)-L_t) / Spread_t
UW_t = (H_t-max(O_t,C_t)) / Spread_t
Body_t = abs(C_t-O_t)
NetMove_t = (C_t-C_(t-1)) / A_t
Gap_t = abs(O_t-C_(t-1)) / A_t
```

NS 是无量纲比例，因此“平均 Spread>1.3”在本规范中必须写为“平均 NS>1.3”，不能拿 1.3 与未经标准化的价格点数比较。

`LW`、`UW` 是下影、上影占比。`CP>=0.35` 不能替代“下影明显”；收盘接近最高点也不能替代 `C>O`。

当 `H=L` 时，CP、LW、UW 为不可用，不填成 0.5。成交量基准为 0 或 ATR 为 0 时，相应指标不可用。涉及不可用指标的规则返回 `not_evaluable`，其他独立且数据完整的规则可继续。

### 4.3 日内成交量季节性

| 运行配置 | 成交量基准 | 使用条件 |
|---|---|---|
| 日线 / 非日内 | 前 20 根均量，20 为 P 参数 | 作为默认研究配置 |
| 日内 `session_matched` | 过去 20 个可比较交易日同一 session、同一 bar slot 的均量 | 同一合约、同一周期；只使用当时可用的历史时段 |

日内不能把夜盘开盘量与午后常态量直接混成同一个季节性基准。V1 的日内配置要求至少 10 个有效同槽样本；不足时量能事件暂不可评估，不静默降级为另一口径。20、10 和基准模式的选择均为 P 类配置；各模式的计算公式固定。

### 4.4 零量、异常时段与换月

- 真实存在的零量 K 线保留，但不触发低量 Spring、Test、ST 或 Absorption；缺失 K 线不能填零冒充真实交易。
- 休市不生成 K 线，不计入 3～10 根等窗口；交易时段内缺失应有 K 线时，暂停受影响窗口并输出 `data_gap`。修复前不使用不完整窗口确认事件。
- 涨跌停锁价、异常成交、合约切换等受影响 K 线不参与强事件确认，输出限制原因。
- V1 默认在实际合约切换后重置均量、ATR、区间、候选和波浪，并重新预热。使用连续调整序列的研究属于另一明确标记的数据配置，不能与实际合约输出混用。
- 数据后来修订时，保存旧实时版本与修订版本；实盘回放依据当时版本，不能用修订数据假装当时已经知道。

### 4.5 时间与数值细节

`t0+3～t0+10` 指第 3 至第 10 根后续有效交易 K 线，包含两端。两根内收复指“刺破当根或紧接的下一根”，不是允许再等待两根。

单根首次可用时间不早于 `max(bar_end, received_at)+实际计算延迟`；多根条件使用所有相关数据的最晚到达时间。迟到的 K 线只能在迟到后影响实时判断，不能倒写回原收盘时刻。跨假设共享证据时沿用原证据的实际可用时间。

V1 价格输入按合约 tick 规则标准化，用整数 tick 或十进制定点表示比较边界。阈值在实际比较前不先四舍五入；图上显示精度不影响规则。一个 tick 的大小来自合约规格，不属于可以拟合的市场阈值。

## 5. 趋势背景与交易区间建立

### 5.1 趋势背景

事件 t 的趋势背景从 t-1 及以前计算，避免异常当根自己改变前置趋势定义。

```text
Delta20 = (C_(t-1)-C_(t-21)) / A_t
ER20 = abs(C_(t-1)-C_(t-21))
       / sum(abs(C_i-C_(i-1)), i=t-20,...,t-1)
Slope20 = OLS_slope(C_(t-20),...,C_(t-1)) / A_t
```

方向效率 ER 的分母为 0 时定义为 0。OLS 使用等距序号 0～19；斜率单位是每根 K 线的价格变化，再除以 ATR。

下跌背景要求同时满足：

```text
C_(t-1) < SMA20_(t-1) 且 C_(t-1) < SMA50_(t-1)
Delta20 <= -2.0
Slope20 <= -0.05
ER20 >= 0.30
```

上涨背景对称：价格高于两条均线、`Delta20>=2.0`、`Slope20>=0.05`、`ER20>=0.30`。

这表示观察窗内具有足够的方向性，不表示每一根都必须下跌或上涨。默认预热至少 100 根；如果实际配置要求更长历史，按更长者执行。均线周期、20 根窗口、斜率、位移和效率阈值均待验证。

### 5.2 支撑、阻力及容忍度

区间建立时保存：

```text
S = 固定候选下沿
R = 固定候选上沿
M = (S+R)/2
A_ref = 路径B用建立区间前一根ATR；路径A沿用高潮事件的A_SC或A_BC
epsilon = max(2 * tick_size, 0.10 * A_ref)
W = R-S
```

支撑区域为 `[S-ε,S+ε]`，阻力区域为 `[R-ε,R+ε]`。区间宽度要求 `3*A_ref <= W <= 12*A_ref`。ε 和 A_ref 随该区间一起冻结；期间波动变化不会改变旧事件所引用的边界。

区间年龄定义为“从原点到当前的有效交易 K 线数，包含原点和当前根”。建立后的 `bars_since_established` 单独保存；15 根、25 根成熟条件使用前者，但事件始终要求区间已经建立。记录 `origin_time` 与 `established_at`，不能把区间年龄当成建立时间。

默认建立失败时返回 `range_candidate_rejected` 及原因，不强行压缩或扩张区间。一个新建立的区间只能从下一根 K 线开始用于新事件检测。

### 5.3 建立区间的两条路径

**路径 A：高潮—反应—测试。** SC→AR_RALLY→ST 或 BC→AR_REACTION→ST 按第 7 节建立 `[S,R]`。区间原点为高潮事件时间，实际建立时间为 ST 确认时间；年龄可以从原点计算，但建立之前不能使用这个区间检测 Spring/JOC。

**路径 B：一般震荡区间。** 没有明显高潮时，使用截至建立时刻的最近 30 根有效 K 线：

```text
S = min(L)
R = max(H)
ER30 <= 0.25
至少 80% 的收盘位于 [S+epsilon, R-epsilon]
上下边各至少 2 次有效触碰
```

下沿触碰：K 线范围与支撑区域相交；上沿触碰：K 线范围与阻力区域相交。每一侧按时间从早到晚贪心选取触碰：相邻计数触碰至少间隔 3 根，且中间至少一根离开该侧区域。`ER30` 按第 5.1 节相同公式使用 30 个收盘变化计算，需要 31 个收盘。

上下沿取样包含建立当根，但事件检测必须使用此前已存在的区间，因此不构成“用当前最高价判断自己是否突破”。路径 B 只能确认工程上的震荡区间，不能凭此确认吸筹、派发或 Phase A。

### 5.4 区间生命周期与选择

V1 每个“实际合约＋周期”最多一个前台区间。前台已有区间时，不在其内部反复重建边界；新建嵌套或跨周期区间属于扩展版本。

没有前台区间时，若同根路径 A 与路径 B 都完成，优先路径 A；同方向多个路径 A 候选按最早创建时间确定。已有前台区间时，新完成的高潮序列作为该区间的附加证据保存，不覆盖 S/R；只有旧区间退出后才允许建立新的前台区间。路径 B 原点是其 30 根取样窗的第一根。

```text
building -> active -> exit_up_candidate / exit_down_candidate
                     -> exit_up_accepted / exit_down_accepted
                     -> retired
active -> expired
```

普通突破对应 `exit_*_candidate`；边界外连续维持满足第 7.5 节时，转为 `exit_*_accepted`。该状态表示突破获得延续证据，尚不等于 Phase E。上破或下破发生后，旧边界继续作为回测和失败判断的参照。

回到区间且突破假设失效时，恢复 `active`，但不能恢复原突破假设的有效状态。新建区间只在旧区间超时，或已达到 Phase E 外侧趋势后再形成一个满足路径 B 的新整理范围时执行；后者同时将旧区间改为 `retired`，保留旧边界供历史假设监测。没有新整理时不每天移动原边界。

默认区间最长前台年龄为 200 根。达到期限仍无明确外部趋势时，标记 `expired`，下一根起允许建立新 ID；不能把超时解释成涨跌方向。已有突破后的回测监测可以引用归档边界直到自身窗口结束。

## 6. 单点和微结构事件规则

本节判断“形态是否发生”；结构假设按照第 7 节更新。条件中的默认数字全部属于 P 类。

### 6.1 SC / BC 特征

**SC 特征，单根版本：**

```text
前置下跌背景成立
L_t < min(L_(t-20),...,L_(t-1))
RVOL_t >= 2.5
NS_t >= 1.8
CP_t >= 0.35
LW_t >= 0.25
V_t > 0
```

输出事实 `SC_FEATURE`，并创建止跌假设 `SC_BOTTOM_CANDIDATE`。不要求 SC 必须是阴线，允许高量、宽幅且从低点明显收回的阳线。

BC 对称：上涨背景、创此前 20 根新高、`RVOL>=2.5`、`NS>=1.8`、`CP<=0.65`、`UW>=0.25`。输出 `BC_FEATURE` 和止涨候选。

V1 不自动把连续 3 根拼成 SC/BC，以保持量能比较对象一致。多根高潮属于后续规则版本；未满足本规则不等于不存在止跌或止涨。

### 6.2 努力与结果背离 / 吸收候选

**单根窄幅高量：**

```text
RVOL_t >= 2.0
NS_t <= 0.7
V_t > 0
```

输出 `EFFORT_RESULT_NARROW_BAR`。若存在事前已知区间且本根触及支撑 / 阻力区域，分别增加 `SUPPORT_ABSORPTION_CANDIDATE` / `RESISTANCE_ABSORPTION_CANDIDATE`，仍不直接确定成交主体或方向。

**三根高量低净推进：**

```text
mean(RVOL_(t-2), RVOL_(t-1), RVOL_t) >= 2.0
abs(C_t-C_(t-3)) / A_t <= 0.5
三根各 V>0，且同一合约、连续有效数据
```

输出 `EFFORT_RESULT_LOW_PROGRESS`。该规则允许三根内宽幅反复成交，不要求每根都是窄幅。可另报路径距离 `sum(abs(C_i-C_(i-1)))/A_t`，用于区分安静停滞和剧烈往返，V1 不赋予固定吸筹含义。

吸收方向的后续证据：支撑附近背离之后 1～5 根内出现 SOS，或 `C>O,NetMove>=0.5,CP>=0.70` 的向上反应，确认 `SUPPORT_RESPONSE_SEQUENCE`，增强承接解释。此前若连续两根收盘 `<S-ε`，承接候选失效。阻力附近对称，向下反应要求 `C<O,NetMove<=-0.5,CP<=0.30`，连续两根收盘 `>R+ε` 使供应候选失效。第 5 根仍无合格反应则超时。缺少区间上下文时，只报量价背离事实。

### 6.3 Spring：下穿与收回

前置条件：已建立且未失效的区间，年龄至少 15 根；检测前已知 S、R、ε。

刺破第一根 p：

```text
L_p < S-epsilon
C_(p-1) >= S-epsilon
(S-L_p)/A_p <= 2.0
V_p > 0
```

创建 `SUPPORT_UNDERCUT_WATCH`，最多观察“p 或 p+1”。若未收回，记录观察超时；这是暂未满足 Spring，不等于已确认 FTI。

收回根 r：

```text
r 属于 {p, p+1}
C_r > S+epsilon
CP_r >= 0.70
V_r > 0
```

模式区间为 p～r，保存最低价、总量、每根平均量、最大 RVOL。按 `max(RVOL_p,...,RVOL_r)` 分组：

- `<0.8`：`SPRING_LOW_VOLUME`。
- `>1.3`：`SPRING_HIGH_VOLUME`。
- 其他：`SPRING_OTHER`，包括恰好等于 0.8 或 1.3。

低量分组要求模式内每根 RVOL 均可用且成交量大于零。没有供应成交与没有有效交易数据必须区分。

若模式 p～r 的任一最低价导致 `(S-min(L_p,...,L_r))/A_p>2.0`，记录 `DEEP_UNDERCUT`，不自动归入上述 Spring 组。两根收回的“发生时间”记录第一根刺破，检测 / 可用时间记录实际收回根。UT 同样检查完整模式的最大上穿深度，避免只检查第一根而漏掉第二根深穿。

Spring 成立时仅支持 Phase C 候选。低量 Spring 仍可能失败；后续 Test 或 SOS 才增加供应测试成功的证据。

### 6.4 普通突破、JOC 与 FTI

**普通向上突破：**

```text
C_(t-1) <= R+epsilon
C_t > R+epsilon
```

输出 `BREAKOUT_UP`。前置要求区间已经建立且年龄至少 15 根。

在普通向上突破基础上，强 JOC 还要求：

```text
C_t > O_t
RVOL_t >= 1.8
NS_t >= 1.5
CP_t >= 0.75
NetMove_t >= 0.5
```

同时输出 `JOC` 事实，创建 `UP_BREAKOUT_VALIDITY` 候选。相同事件 ID 关联多个特征标签，不能计作多次独立证据。

**普通向下突破：** `C_(t-1)>=S-ε` 且 `C_t<S-ε`。强 FTI 增加 `C<O`、`RVOL>=1.8`、`NS>=1.5`、`CP<=0.25`、`NetMove<=-0.5`。

跳空后窄幅越界可能只满足普通突破，不满足 JOC/FTI。`Gap>=1.0` 时增加 `gap_breakout` 标签，不将包含跳空的 True Range 冒充宽实体。

### 6.5 区间内部 SOS / SOW

已有区间、年龄至少 15 根时：

```text
SOS: C>O, NS>=1.3, RVOL>=1.4, CP>=0.70, NetMove>=0.5
SOW: C<O, NS>=1.3, RVOL>=1.4, CP<=0.30, NetMove<=-0.5
```

无已知区间时可输出同样的量价事实，名称用 `STRONG_UP_BAR` / `STRONG_DOWN_BAR`，不自行建立维科夫阶段。SOS 不必突破外部 R；SOW 不必跌破外部 S。

### 6.6 UT / UTAD 候选

UT 是第 6.3 节价格方向的镜像：刺破前收盘 `C_(p-1)<=R+ε`，已知区间上沿被超过 ε 刺破，深度不超过 2 ATR，在刺破当根或下一根收于 `R-ε` 下方，`CP<=0.30`，模式内有真实成交。成交量不作为所有 UT 的必要门槛。

输出 `UT_FEATURE`。只有区间年龄至少 25 根，且刺破前已存在第 8 节的供应占优证据，才额外创建 `UTAD_CANDIDATE`；随后 1～12 根内的 SOW 或合格 LPSY 提高派发后上冲解释的证据。

一个 JOC 后的失败先标记 `FAILED_UP_BREAKOUT`。若失败模式另外满足 UT 条件才追加 UT；没有成熟派发上下文时不追加 UTAD。

## 7. 后续确认、失效与超时规则

### 7.1 通用生命周期

事实事件在满足条件时写入，保持不变。结构假设采用：

```text
candidate -> confirmed
candidate -> invalidated
candidate -> expired
confirmed -> invalidated
confirmed -> expired
```

`confirmed` 的准确含义是“截至确认时，规定后续规则已经满足”。它不代表真实吸筹标签被永久证明。假设一旦失效或超时，不复活原 ID；后续出现新证据需创建新假设并关联旧事件。

同一根同时出现确认和失效条件时，**先执行失效，再执行确认**。窗口末根可确认，末根处理完仍未满足才超时。所有转换追加时间记录。

### 7.2 SC→AR→ST：止跌候选闭环

SC 出现在 t0，保存 `L_SC`、`V_SC`、`NS_SC` 和 `A_SC`。此时区间尚未建立，因此另行冻结候选容忍度 `epsilon_SC=max(2*tick_size,0.10*A_SC)`，用于闭环形成前的失效与 ST 判定；不得等待 ST 出现后再决定原候选的容忍度。

**AR_RALLY 确认，观察 t0+3～t0+8：**

```text
p = t0+1 至当前 t 的最高 H 所在根；同值取最早
H_p-L_SC >= 2.0 * A_SC
C_t < C_(t-1) < C_(t-2)
H_p-C_t >= 0.5 * A_SC
```

首个满足条件的时刻记为 `ar_confirmed_at`，AR 高点为 H_p，候选边界固定 `S=L_SC, R=H_p`，并沿用 `A_ref=A_SC`、`epsilon=epsilon_SC`。高点位置 p 可以早于确认根，但不能在 p 时提前使用后来确认的信息。上述两根回落是因果转折确认方法，存在识别延迟，待验证。

**ST 确认，观察 AR 确认后第 5～15 根：**

```text
S-epsilon <= L_t <= S+epsilon
C_t > O_t 且 C_t >= S+epsilon
V_t < 0.60 * V_SC 且 V_t>0
NS_t <= 0.70 * NS_SC
```

允许 ST 比 SC 略低，但最多 ε；不要求任何新低都必须否定测试。通过 ST 且区间宽度有效时，建立路径 A 区间，记录 `SC_STOPPING_SEQUENCE` 和“止跌结构已获得规则支持”。Phase A 获支持，方向仍可以在后续演变为再派发。

**失效：** 在闭环形成前，任意收盘 `<L_SC-ε`，则该 SC 止跌假设失效。该严格条件与 ST 允许少量盘中下穿并不矛盾。之后的新高潮可产生新候选。

**超时：** 未在 t0+8 前确认 AR，则 AR 路径超时；已确认 AR 但未在其后第 15 根确认 ST，则该闭环超时。不把超时转换成派发结论。

BC 闭环保存 `H_BC,V_BC,NS_BC,A_BC`，冻结 `epsilon_BC=max(2*tick_size,0.10*A_BC)`。AR_REACTION 在 BC 后 3～8 根中按下列规则确认：

```text
p = BC 后到当前的最低 L 所在根；同值取最早
H_BC-L_p >= 2.0 * A_BC
C_t > C_(t-1) > C_(t-2)
C_t-L_p >= 0.5 * A_BC
```

冻结 `S=L_p,R=H_BC,A_ref=A_BC,epsilon=epsilon_BC`。随后 5～15 根的上沿 ST 要求：`R-ε<=H_t<=R+ε`、`C_t<O_t`、`C_t<=R-ε`、`0<V_t<0.60*V_BC`、`NS_t<=0.70*NS_BC`。闭环形成前任意收盘 `>H_BC+ε` 使止涨假设失效；超时规则与 SC 一致。

### 7.3 Spring→Test / SOS

Spring 收回时间为 tS，保存模式最低价 `L_SP`、模式平均单根成交量 `V_SP_mean`、冻结 ε、S、R。

**单根 Test，观察 tS+3～tS+10：**

```text
L_t >= L_SP+epsilon
S-epsilon <= L_t <= S+0.5 * A_t
C_t > O_t
C_t > H_(t-1) + tick_size
C_t > S+epsilon
V_t < 0.65 * V_SP_mean 且 V_t>0
RVOL_t < 0.85
NS_t <= 1.0
```

该规则明确要求再次接近支撑，不能用远离支撑后的普通上涨冒充 Test。多根 Spring 的量能比较使用平均单根量，不将两根总量与单根量直接比较。

高量 Spring 必须通过 Test 才能输出 `SPRING_TEST_CONFIRMED`；低量 Spring 和其他 Spring 可以通过相同 Test 增加证据。低量 Spring 还允许在 tS+1～tS+10 出现 SOS，输出 `SPRING_SOS_SEQUENCE`，但不能把 SOS 名称替代高量 Spring 所需的测试证据。

**失效：** 任意收盘 `<L_SP-ε`，或连续两根收盘 `<S-ε`。失效优先于当根的确认。**超时：** 第 10 根结束后未出现指定确认动作，相关测试候选 `expired`；Spring 历史形态保留。

输出观察信号可以叫 `spring_test_supported`。原文“Buy Test #1”只适合作为独立策略研究名称，不是维科夫所有版本通用的事件编号。

### 7.4 JOC→BUEC→LPS：严格回测路径

JOC 收盘时间为 tJ，冻结原 R、ε及突破根实体。观察完成时刻必须在 tJ+3～tJ+12 内。

1. **回调起点 b：** 突破后第一个 `C_b<C_(b-1)` 的 K 线；若窗口内没有回调，记录没有 BUEC 路径，不强行构造。
2. **触边根 q：** 回调中 `R-ε<=L_q<=R+ε`；q 之前到 b 的各根低点均不得低于 R-ε。
3. **回调证据：** b～q 至少 3 根；`mean(RVOL)<0.85`、`mean(NS)<=1.0`，且 RVOL 对根序号的 OLS 斜率 `<0`。这里用负斜率描述总体缩量，不要求每根机械递减。
4. **向上确认根 r：** 位于 q+1～q+3，且整体完成不晚于 tJ+12。r 之前该回调的最低价继续不低于 R-ε。

回调任何一根低点 `<R-ε`，使本轮严格 BUEC 候选 `invalidated`，即使收盘尚未触发突破有效性的失效条件。这里分别判断“严格回测形态失败”和“突破解释失效”，不得将二者合并。窗口内不复活原 BUEC 候选。

向上确认根必须满足：

```text
C_(r-1) < O_(r-1)                    # 前一根阴线
C_r > O_r
O_r <= C_(r-1) 且 C_r >= O_(r-1)     # 阳线实体吞没前一根阴线实体
C_r > H_(r-1) + tick_size
C_r > R+epsilon
RVOL_r >= 1.2
```

首个符合完整条件的 r 同时确认 `BUEC_SEQUENCE` 与 `LPS_AT_CREEK`，突破持续有效解释获得增强。不能仅在 q 触边时就将 LPS 当成已确认事实。

如果发生多次触边，按时间逐一检查；达到更低、但仍合规的触边低点时更新未确认候选 q，已确认记录不覆盖。b 固定为本轮回调起点。

**放宽版本处理：** “回撤不超过 JOC 实体的 50%”只保存为 `shallow_body_retrace` 附加证据，不与“守住 R”用 OR 连接。即使实体回撤很浅，只要回到 R 下方不符合严格条件，就不能确认本版本 BUEC。

附加证据的具体算法：JOC 必须有正实体；令 `pullback_low=min(L_b,...,L_r)`，`body_retrace=max(0,C_tJ-pullback_low)/(C_tJ-O_tJ)`，`body_retrace<=0.50` 时记为浅实体回撤。它只描述相对突破收盘的回撤，不代表触边或后续确认已经完成。

### 7.5 不出现 BUEC 的延续与突破失败

**延续路径：** 任意普通突破后连续 3 根收盘位于原边界外侧，记录 `BREAKOUT_HOLD_CONFIRMED`。向上要求每根 `C>R+ε`，向下要求每根 `C<S-ε`，包含突破根。该标签说明边界外维持，不等同于完成 BUEC/LPS，也不必等待回调。

**向上突破失效：** 满足任一：

- 突破后连续 2 根收盘 `<R-ε`。
- 突破后任意一根收盘 `<M`，即重新深入原区间下半部。

向下对称：连续 2 根收盘 `>S+ε`，或任意收盘 `>M`。

收盘在边界的容忍带内是中性状态，不计入连续越界或连续回区间计数。失败后保留 JOC/FTI 事实，并更新有效性假设为 `invalidated`。即使此前 BUEC 已确认，这些失效标准继续有效。

“连续”指相邻有效交易 K 线均满足；任意一根不满足即将该连续计数重置为零。不能跳过容忍带内的一根，再把前后两根计作连续。突破有效性候选若到突破后第 12 根既未满足外侧维持，也未满足严格回测，则 `expired`，不等同于 `invalidated`。

BUEC 12 根窗口结束仅使“规定时间内严格回测”的候选超时。如果已有延续证据且没有失效，突破有效性假设可以继续成立；不能把未出现 BUEC 当成假突破。

### 7.6 FTI→反弹测试→LPSY

按 BUEC 规则反向执行：FTI 后反弹，在原 S 附近的最高价不超过 S+ε，反弹至少 3 根、平均 RVOL<0.85、平均 NS<=1.0、量能斜率<0；随后阴线吞没前一根阳线实体，`C<L_previous-tick`、`C<S-ε`、RVOL>=1.2。

确认点在触边后 1～3 根，完成于 FTI 后 3～12 根。输出 `LPSY_AT_ICE`，用于增强供应占优解释。下破失效按第 7.5 节执行。

参数初始与多头路径相同仅为便于建立基线；多空可分别校准并登记，不能假定完全对称。

### 7.7 事件重叠和候选数量

同根可同时存在窄幅背离、支撑触碰、UT 等标签；同一个量价事实的多个别名不计作多条独立信息。JOC 通常也满足 SOS，保存关联关系 `JOC implies SOS_features`。

每个区间、每种闭环路径最多一个活动候选。候选失效或超时后，新条件触发才建立新 ID。已经活动的 SC 候选遇到新 SC 特征时，保留事实但不偷偷更换原低点；原候选失效后才允许新高潮创建替代路径。候选替换依据也属于版本规则。

### 7.8 结构解释的统一退出规则

序列事实确认后保留，但“截至现在该解释仍有效”继续接受检查。采用以下默认规则，时间长度和次数仍为 P 类：

| 假设 | 后续退出或降级 |
|---|---|
| SC/BC 止跌 / 止涨解释 | 闭环后连续两根收盘穿越原高潮边界的失效侧，或原区间被相反方向有效突破时，`invalidated`；进入后续阶段时保留旧确认事实，旧的当前阶段标签 `expired` |
| 支撑 / 阻力吸收解释 | 与第 6.2 节相同失效规则继续适用；最近反应证据超过 10 根则当前解释 `expired` |
| Spring 供应测试解释 | 与第 7.3 节相同价格失效规则继续适用；相关证据超过 20 根且没有新的测试 / SOS / LPS，则当前解释 `expired` |
| UTAD 派发后上冲解释 | 模式最高价为 H_UT；收盘 `>H_UT+ε`，或连续两根 `>R+ε` 时 `invalidated`；12 根内没有 SOW/LPSY 则候选 `expired` |
| BUEC/LPS 与 LPSY 位置解释 | 原严格回测序列事实保留；突破有效性按第 7.5 节失效，当前支撑 / 供应解释同步失效 |
| 吸筹 / 派发、再吸筹 / 再派发候选 | 相反方向占优证据连续 2 根成立，或发生相反方向外侧维持时 `invalidated`；原方向证据不再满足且近期信号过期，则 `expired` |
| Phase C / D / E 当前解释 | 底层引用假设失效时同步撤销；前进到后续阶段时保留过去已确认记录，旧“当前阶段”标签过期；没有独立证据时返回未知，不硬退回某个固定阶段 |

区间方向标签 `demand_dominance_by_rules` 和 `supply_dominance_by_rules` 是逐根重算的证据；结构假设是有历史的对象，二者不能共用一个字段。相反方向占优条件不足时，只能称为支持减弱，不能自动认定对方已经占优。

## 8. 因果波浪量与区间方向假设

### 8.1 V1 波浪划分方法

本节是受到 Weis 波浪量思路启发的明确工程实现，不宣称与某商业指标逐根一致。输入只使用收盘价格，默认反转阈值为波浪建立时已知 ATR 的 1.0 倍。

**初始化：** 以第一个有效收盘为锚点，固定 `rho=1.0*ATR_previous`，暂存后续量能。只有收盘离锚点达到 rho 才确定第一波方向。此前输出 `wave_initializing`；方向确定时才公布第一波的起点及已累计量，不能倒填此前已知方向。

初始化锚点根的成交量不归第一波；第一波从锚点之后第一根开始累计，`start_reference_close` 为锚点收盘。锚点及预热阶段数据保留，但不参与已完成波比较。

**上行波：** 维护当前波已知最高收盘 `E`。如果新根 `C_t<=E-rho`，在 t 收盘确认反转；旧波结束于 t-1，旧波 `confirmed_at=t`。反转根 t 的成交量归新下行波，新波的基准价格为 `C_(t-1)`。否则把 V_t 加入旧波并更新 E。

**下行波：** 维护最低收盘 E；若 `C_t>=E+rho`，同样确认反转并从 t 建立上行波。

每个新波的 rho 在建立时冻结为 `wave_reversal_atr * ATR_(t-1)`。相等满足反转；平收且未达到反转阈值时延续当前波。旧波不会因后来发现更早极值而重新分配成交量。

这是一种有确认延迟的因果划分。经典视觉波浪可以把终点放在极值，本版本把量能分配固定在可执行的反转确认边界；两种算法的结果不能混用。

### 8.2 波浪字段和可比较指标

```text
wave_id, direction, start_time, end_time, confirmed_at, available_at
status: initializing / forming / completed
start_reference_close, extreme_close, atr_at_start, reversal_threshold
bar_count, raw_volume_sum, baseline_volume_sum
wave_rvol = raw_volume_sum / baseline_volume_sum
wave_result = abs(extreme_close-start_reference_close) / atr_at_start
wave_speed = wave_result / bar_count
mean_bar_ns = mean(NS_i)
```

`baseline_volume_sum` 是该波每根事前成交量基准 Bv_i 的和。`wave_rvol` 避免把持续很长的波天然认成更强努力。累计原量仍保存供研究。

形成中的波随新 K 线更新，可以展示但不能与已完成波混作同口径验证标签。涉及基准不可用的波不进入方向统计。

### 8.3 区间供求占优证据

区间年龄至少 25 根，取本区间内最近最多 6 个已完成波，要求至少 2 个上行波和 2 个下行波。一个波必须完整位于该区间原点之后，且该波所有收盘位于 `[S-ε,R+ε]`；跨原点或跨区间外的波不计。统计使用各方向的中位数。

需求占优的四项证据：

| 项目 | 默认条件 |
|---|---|
| 相对努力对比 | 上行 wave_rvol / 下行 wave_rvol >= 1.2 |
| 推进速度对比 | 上行 wave_speed / 下行 wave_speed >= 1.2 |
| 单根波幅对比 | 上行 mean_bar_ns / 下行 mean_bar_ns >= 1.2 |
| 努力与回调组合 | 上行 wave_rvol >=1.4 且下行 wave_rvol <=0.85 |

默认满足至少 3 项记为 `demand_dominance_by_rules`；供应占优按上下行互换。分母为零或指标不可用时该项为不可评估，不填无穷大；至少 3 项真实可评估且满足才允许占优标签。

方向对比比例、波数和“满足 3 项”都待验证。它们是规则证据，不是 75% 胜率，也不是直接观测的主动买卖量。需求和供应都未达到门槛时输出中性或信息不足。

### 8.4 吸筹、派发和再吸筹 / 再派发假设

```text
吸筹候选：成熟区间 + demand_dominance_by_rules + 最近10根出现 SOS
派发候选：成熟区间 + supply_dominance_by_rules + 最近10根出现 SOW
```

最近 20 根存在仍有效的 Spring 相关测试 / SOS 闭环，或已确认的 LPS 时，增强吸筹解释；UTAD 相关弱势闭环或 LPSY 对称增强派发解释。没有这些闭环时保留候选，不硬性排除无 Spring 的结构。

区间建立时保存更大尺度背景：默认采用同周期前 50 个收盘变化的方向，净位移至少 3 ATR 且 ER>=0.30。上涨背景中出现吸筹证据显示“再吸筹候选”；下跌背景中出现派发证据显示“再派发候选”。背景不足时只输出一般吸筹 / 派发候选。

这里的“更大尺度”是同周期更长窗口，不冒充已确认的高周期趋势。日后加入真实高周期时，只能使用当时已收盘且已到达的数据。

## 9. 实时状态、记录格式与处理顺序

### 9.1 市场状态与阶段输出

主状态枚举：`uptrend / downtrend / range / transition / unknown`。

按如下优先级：

1. 核心价格数据缺失或必要预热不足：`unknown`，说明具体缺项。
2. 已知前台区间内，收盘仍位于 `[S-ε,R+ε]`：`range`；另报长期趋势背景，不强行把二者合并成同一个结论。
3. 位于区间外，但延续未满足或相应趋势尚未成立：`transition`，报告突破候选。
4. 已有外侧延续、且当前趋势条件成立：按照方向输出 `uptrend` 或 `downtrend`。
5. 没有前台区间时：当前趋势条件成立则报方向，否则 `transition`，含义为未形成明确趋势或有效区间。

当前状态的趋势计算使用截至本根的数据；第 5.1 节用于事件前置背景的趋势仍截至上一根。这两个时间口径必须在代码中分开命名。

非数据质量导致的主状态切换，默认需要目标状态连续出现 2 次原始分类；切换前保存 `pending_regime`。数据失效立即切到 `unknown`，不等待两根。突破事实不等待主状态防抖。

阶段输出采用证据映射：

- SC/BC 闭环：Phase A 获规则支持。
- 成熟震荡区间：Phase B 候选，方向可未知。
- Spring / 成熟 UT：Phase C 候选；测试或相应强弱闭环增强证据。
- SOS 与合格 LPS / SOW 与合格 LPSY：相应 Phase D 获规则支持。JOC/FTI 单独只提供 Phase D 候选证据。
- 外侧连续至少 5 根、当前方向效率 ER20>=0.40，且距原 R 向上 / 原 S 向下至少 2*A_ref：相应 Phase E 获规则支持。

多个阶段解释可以并存或保持未知。`phase_supported_by_rules` 必须附证据 ID、确认时间和失效条件，不能只输出一个没有依据的字母。

### 9.4 每根 K 线的处理顺序

```text
1. 校验数据、合约和时段；处理换月、缺失、预热。
2. 取得仅截至上一根的指标、趋势背景、既有区间及冻结边界。
3. 检查已有假设的失效条件，追加失效记录。
4. 检测本根单点 / 两根 / 三根事实事件，创建允许的新候选。
5. 检查未失效候选的后续确认，包括窗口末根。
6. 对仍未满足确认的到期候选追加超时记录。
7. 推进因果波浪，并更新截止本根的指标与区间方向证据。
8. 更新市场状态和阶段解释；需要重建区间时登记新ID，下一根才启用。
9. 写出事件、假设转换、实时快照及实际可用时间。
```

用于新事件的成熟派发上下文取第 2 步快照，不能用第 7 步刚形成的供应占优证据反称刺破前已知。第 7 步的证据可以用于当下新增的结构解释，但要写出对应可用时间。

## 11. 验证方案与验收要求

### 11.1 工程正确性：必须通过

| 验收项 | 必须得到的结果 |
|---|---|
| 前缀回放一致性 | 只输入到 t 的回放结果，与全量回放中保存的 t 当时快照完全一致 |
| 未来扰动检查 | 修改 t 之后的数据，不改变截至 t 的事件、边界、波浪和状态记录 |
| 后续追认检查 | t+N 的确认不能出现在 t 的历史可用状态中 |
| 边界检查 | 当前 K 线不抬高自身阻力；失败后原 S/R/ε 不移动 |
| 窗口检查 | 确认可发生在窗口末根；末根之后不再确认原候选 |
| 冲突检查 | 同根失效与确认冲突时，失效优先 |
| 数据质量检查 | 零量、缺失、H=L、ATR=0、换月、锁板返回明确原因 |
| 波浪检查 | 形成中 / 完成区别明确，反转根不回分旧波，完成可用时间正确 |
| 版本检查 | 输出完整保存数据、规则和参数版本，可重放同一结果 |

这些检查验证工程正确性，不能替代统计有效性。本文为规范交付，尚未产生可执行识别器或上述检查结果。

### 11.2 识别质量优先于交易收益

优先统计候选数量、覆盖率、候选确认率、失败率、超时率、确认延迟、状态切换次数和不同质量标记下的可评估比例。必须报告分母；只报告被确认的漂亮案例会造成选择偏差。

对于吸筹等潜在解释，可以使用多人独立标注及一致性评估，但人工标签不是机构真实意图。更适合的客观评价对象包括：

- 候选出现后的固定 N 根内，先越过上侧目标还是先越过下侧失效点。
- 突破后未来 N 根中，边界外收盘占比与最大回区间深度。
- 信号后向有利 / 不利方向的最大价格变化，以事前 ATR 标准化。
- 既有背景、简单均线和普通区间突破相对加入维科夫特征后的增量差异。

预测目标、观察期限和阈值都需预先登记为单独的评价配置，不能评价时挑最有利未来路径。一个假设自身规则“确认率高”并不足以说明存在增量预测信息。

第一版可采用独立的评价基线：从信号实际可用后的下一根开始观察 20 根，价格锚点取信号根收盘，冻结上下各 2 个事前 ATR 的障碍，记录先触及哪侧、都未触及及无法确定。20、2 和锚点选择属于待验证的评价参数，不参与事件成立判断。

只有 OHLC 时，同一根可能同时触及上下障碍，不能凭希望的方向规定先后。应标记 `ambiguous_intrabar`，或用当时可获得的更细数据判定；样本末端观察期未满记为 `censored`。未命中、歧义与删失分别报告，不能全部丢弃后只统计成功样本。

### 11.3 时间滚动验证

使用按时间排序的训练、验证和最终样本外区间。研究起点可采用 24 个月训练、6 个月验证、6 个月样本外并滚动，但窗口长度同样待验证，要考虑品种有效历史及事件数量。

参数选择只在训练 / 验证区间完成。最终样本外检查前冻结规则和配置。相邻集合中，标签未来观察区间重叠的样本需要 purge；embargo 长度根据最长标签期限与数据重叠决定，不能直接照搬“随机打散 K 线”。

模型预热可以使用测试区间以前的历史，但不能用测试未来重新选参数。不同品种、年份、波动环境、日夜盘、多空方向分别报告结果。

### 11.4 参数优化和概率

先检查默认参数附近的稳定区域，避免只选一个尖峰最优点。可将固定 RVOL 门槛与只使用历史数据的分位数门槛做版本对比；分位数计算方法属于新规则版本，其窗口和分位水平再作为 P 参数。

只有建立明确客观预测对象，并用独立样本校准后，才可输出概率。至少报告校准曲线、Brier 分数及样本量。V1 默认 `probability=null`，只输出证据和状态。

最终统计门槛由业务目标预先确定；本文不把未经验证的“确认率至少 80%”写成验收标准。没有完成样本外验证时，只能声称工程规则可用，不能声称具有稳定交易优势。

### 11.5 以后接入交易层时的额外验证

需要明确交易时刻、下一可成交价、手续费、滑点、涨跌停成交限制、实际合约换月和风险预算。收盘后才能知道的信号不能无条件按同一根收盘价成交。

策略收益、风险和容量必须独立验证。SC、Spring 或 BUEC 标签是否适合入场，不能由事件名字直接决定。

## 12. 实施顺序与参考资料

### 12.1 建议实施顺序

1. 统一实际合约、时段、已收盘输入、指标及版本记录。
2. 实现趋势背景、一般区间与冻结边界，先输出可解释的市场状态。
3. 实现单根 SC/BC、背离、普通突破、JOC/FTI、SOS/SOW 事实。
4. 实现两根 Spring/UT 及候选生命周期，补齐失效和超时。
5. 实现 AR/ST、Spring Test、严格 BUEC/LPS 与 LPSY 序列。
6. 完成前缀一致性和真实可用时间验收，再接入因果波浪与结构方向解释。
7. 冻结默认版本，开展滚动样本外研究；通过后再设计交易层。

实施阶段可单独验收，但未实现模块必须标为 `not_implemented`，不能当成该事件没有发生。对未覆盖的曲线 Creek、内部 LPS、多根高潮和复杂 BU 形态保留明确范围说明。

### 12.2 第一轮校准的重点

完整登记参数的目的在于消除隐藏选择，并不要求第一轮同时优化全部参数。建议先冻结计算口径及所有非重点默认值，仅校准：成交量异常阈值、强事件波幅阈值、边界容忍度、最小区间年龄、Spring 深度和收回期限、确认窗口。第二轮再独立检查趋势过滤、回测严苛程度与波浪方向证据。

采用“关闭某模块 / 添加某模块”的对比，检查它对简单趋势和普通突破基准的增量贡献。若严格 BUEC 样本极少，先报告覆盖率和确认延迟，再研究宽松回测的新规则版本；不能事后把失败案例删除或静默放宽原规则。
